# Customer escalation runbook

## When to use this runbook

Use this path when a customer reports that review comments are missing, attached to stale content, or blocked by provider access.

## First response

Confirm whether the customer is reviewing a public PR, a private PR, a branch document, a Draft Review, or a Live Preview Review.

## Triage checklist

- Check whether the user is signed in.
- Check whether the repository provider still grants read access.
- Check whether refresh or re-anchoring has already run.
- Capture the review route without copying raw customer repository URLs into telemetry.

## Resolution handoff

Summarize the affected review surface, the access state, the latest refresh result, and the remaining user action.
