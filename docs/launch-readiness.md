# Launch readiness review

## Summary

Review Copilot is ready for a controlled rollout to documentation-heavy teams that already use Commentary for rendered Markdown reviews.

The launch should emphasize document-first review, app-native threads, and provider synchronization as a supporting workflow rather than the primary reading surface.

## Launch decision

Ship to the first three design partners after support receives the fallback language and the docs team verifies the customer FAQ.

## Rollback plan

Disable the feature flag for the affected organization, keep existing review threads available, and move active reviewers back to standard rendered Markdown review.

## Open review notes

- Confirm the rollback owner is named in customer-facing copy.
- Add one screenshot of the rendered review shell to the FAQ.
- Make sure support can explain why raw diffs remain available but secondary.
