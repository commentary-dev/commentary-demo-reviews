# Commentary Demo Reviews

This branch contains the PR Markdown sample for Commentary demos, including embedded and standalone visual review artifacts.

## Visual review walkthrough

Open the launch document, activate visual annotation, select a rectangular region, and submit a normal review comment. The PNG is sized for zoom and pan; the source-backed SVG and Mermaid files retain Raw mode. The repeated SVG verifies that markers remain occurrence-specific.

```text
/review/github/commentary-dev/commentary-demo-reviews/pull/1?demo=1&file=docs%2Flaunch-readiness.md
/review/github/commentary-dev/commentary-demo-reviews/pull/1?demo=1&file=assets%2Freview-workflow.svg
/review/github/commentary-dev/commentary-demo-reviews/pull/1?demo=1&file=diagrams%2Frelease-flow.mmd
```

Public viewing is read-only. Creating comments, replies, or status changes requires authentication.
