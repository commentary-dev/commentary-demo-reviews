# HTML Review Demo

This branch contains a static generated report for Commentary HTML Review, including a local raster, safe inline SVG, and a source-backed standalone SVG.

## Visual review walkthrough

Open the report in Preview, activate visual annotation, and select a risk cell, dashboard panel, or the red ownership gap. Zoom and pan remain review controls; the artifact is not modified. Raw preserves the original HTML and SVG source.

```text
/review/github/commentary-dev/commentary-demo-reviews/pull/2?demo=1&file=reports%2Fpartner-migration-readiness.html
/review/github/commentary-dev/commentary-demo-reviews/pull/2?demo=1&file=reports%2Fassets%2Freview-workflow.svg
```

Public viewing is read-only. Creating comments, replies, or status changes requires authentication.
