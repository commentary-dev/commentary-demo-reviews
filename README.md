# Marp Demo

This branch contains a Marp deck for Commentary slide review, including raster, SVG, Mermaid, and repeated visual occurrences.

## Visual review walkthrough

Open the deck in presentation mode, activate visual annotation, and select a region inside the dashboard, workflow, or Mermaid lifecycle. The repeated SVG verifies that markers remain tied to the selected slide occurrence.
